## Performance Guidelines
- Select only needed columns, never use `SELECT *`.
- Filter as early as possible in WHERE clause.
- Avoid cartesian joins (always include ON condition).
- **Always prefer columns marked [PK] or [IDX] in WHERE, JOIN ON, and ORDER BY clauses.**
- **When filtering by foreign key (e.g. category_id, user_id), use the indexed column directly instead of joining then filtering by name.**
- When sorting large result sets, prefer ORDER BY on indexed columns.
- For time-range queries, use indexed timestamp columns with sargable expressions (avoid wrapping indexed columns in functions like date_trunc()).
